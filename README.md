# Portfolio Pessoal

Portfólio responsivo desenvolvido com Flutter Web para apresentar projetos, habilidades técnicas e experiência profissional através de uma interface moderna, animações suaves e arquitetura organizada.

## Funcionalidades

* Layout responsivo para desktop e mobile
* Transições e animações customizadas
* Suporte a tema claro e escuro
* Suporte multilíngue (Português / English)
* Exibição interativa de projetos
* Formulário de contato integrado ao Firebase Firestore

## Stack utilizada

* Flutter
* Dart
* Riverpod
* GoRouter
* Firebase
* Firestore
